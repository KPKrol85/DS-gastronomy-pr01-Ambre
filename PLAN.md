# Ambre — Development Plan

**Last reviewed:** 2026-10-28
**Project type:** Eight-page Polish portfolio demonstration of a fictional restaurant — static HTML, modular CSS, Vanilla JavaScript, Node.js production build and Netlify-oriented hosting rules
**Plan status:** Active

## Planning principles

- The plan reflects the current repository state and the open findings of the 2026-10-26 `AUDIT.md`.
- Canonical sources are the root HTML pages, `css/`, `js/`, `sw.js` and `scripts/`. `dist/` and minified assets are generated by `scripts/build-dist.mjs` and are never edited directly.
- Ambre has no backend, database, accounts or payments by design. Reservation delivery depends on the hosting provider and is not part of the repository contract.
- Main items are checked only when all required subtasks and their verification are complete.
- Resolved audit findings are converted into completion records in `AUDIT.md` under the lifecycle rules in `AGENTS.md`; significant completed changes go to `docs/CHANGELOG.md` only when the approved task permits it.
- Completed earlier cycles are archived in `docs/archive/plans/` and are not repeated here.
