## Project scope

- Ambre is a static demonstration project. Reservation handling uses a Netlify-compatible submission contract; no backend, database, accounts, payments or confirmed provider delivery are included.
- Canonical sources are root HTML, modular CSS and JavaScript. `scripts/build-dist.mjs` generates production assets. Generated `dist/` and minified files are not source files.
- Preserve accessibility, responsive behavior, SEO, light/dark/system themes, native fallbacks and established interaction contracts.
- Historical Phase 1–4 work originates from `docs/archive/plans/PLAN-2026-08-22.md`. Verification records are retained without claiming fresh execution.
